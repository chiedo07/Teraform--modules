# ☁️ Terraform Infrastructure Modules

Reusable Terraform modules for provisioning cloud infrastructure following Infrastructure as Code best practices.

## 🚀 Overview
This project demonstrates how to build modular, reusable infrastructure using Terraform. It focuses on maintainability, scalability, and clean infrastructure design.

## 🧩 Architecture
- Root configuration for infrastructure deployment
- Reusable VNet module
- Remote state backend configuration
- Structured Terraform project layout

## ⚙️ Features
- Modular infrastructure design
- Reusable networking components
- Remote state support
- Clean separation of concerns

## 🛠️ Tech Stack
- Terraform
- Cloud Provider (Azure/AWS)
- HCL (HashiCorp Configuration Language)

## 📦 Usage
```bash
terraform init
terraform plan
terraform apply
